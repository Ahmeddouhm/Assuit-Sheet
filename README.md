# my_Problem_Solving_Journey

My problem-solving journey using C#.

## How to Navigate

All solutions are stored in `Program.cs`.

Since each problem is committed separately, you can browse all solutions through the file history:

👉 [Browse All Solutions](https://github.com/Ahmeddouhm/Assuit-Sheet/commits/main/Program.cs)

### How to find a solution

1. Open the link above.
2. Find the problem by its commit message.
3. Open the commit.
4. View the implemented solution in `Program.cs`.
